### How to run this program:

It's rather simple:

create 3 different terminals for the 3 different nodes (if you want more nodes, just add more addresses under the address variable)

In the different terminals, change path to Distributed_Systems\Mandatory_handins\handin4\node

In each terminal run the following command: go run . -id <address id>

Congrats, you have now run the program

The log files, gets created by themselfs, if no log file exists
